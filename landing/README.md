# Лендинг студии сайтов-визиток и лендингов

Статический сайт: чистые HTML, CSS и JavaScript. Ничего устанавливать не нужно.

## Структура
```
landing/
├── index.html      — страница (все тексты здесь)
├── css/style.css   — оформление (цвета — в начале файла, блок :root)
├── js/logger.js    — модуль логирования (уровни debug/info/warn/error, JSON)
├── js/main.js      — меню и форма заявки (настройки — объект CONFIG вверху)
└── README.md
```

## Как посмотреть сайт у себя
1. Скачайте папку `landing` на компьютер.
2. Откройте файл `index.html` двойным щелчком. Он откроется в браузере.

## Как поменять тексты и цены
1. Откройте `index.html` в «Блокноте» (или в VS Code).
2. Найдите места в квадратных скобках, например `[Название студии]` или `от [___] ₽`.
3. Замените их своими данными и сохраните файл (Ctrl+S). Обновите страницу в браузере (F5).

Что заменить обязательно: название студии, цены и сроки, реквизиты и контакты в футере, ссылку на Telegram (также в `js/main.js`, поле `fallbackContactUrl`), примеры работ и отзывы.

## Как подключить форму заявки
Сайт статический, поэтому заявки нужно куда-то отправлять. Самый простой способ:
1. Зарегистрируйтесь на сервисе Formspree (formspree.io) и создайте форму. Вы получите адрес вида `https://formspree.io/f/xxxxxxx`.
2. Откройте `js/main.js` и вставьте адрес в `formEndpoint` в объекте `CONFIG`.
3. Отправьте тестовую заявку. Она придёт на вашу почту.

Пока адрес пуст, форма предлагает посетителю написать в Telegram.

## Как опубликовать
**Вариант 1 — Netlify (проще всего):** зайдите на app.netlify.com/drop и перетащите папку `landing` в окно браузера. Сайт сразу получит адрес.

**Вариант 2 — GitHub Pages:** в репозитории откройте Settings → Pages, выберите ветку и папку с сайтом.

Свой домен (например, mysite.ru) покупается у регистратора и подключается в настройках Netlify или GitHub Pages.

## Логи
Все важные события пишутся в консоль браузера (F12 → вкладка Console) в формате JSON. Телефоны и email маскируются автоматически. Чтобы отправлять логи во внешнюю систему, передайте функцию `transport` при создании `new Logger({ transport: fn })` в `js/main.js`.

Пример записи об ошибке отправки формы:
```json
{
  "timestamp": "2026-10-02T12:00:00.000Z",
  "level": "error",
  "message": "Не удалось отправить форму заявки",
  "requestId": "req_8f3a2c",
  "function": "submitLeadForm",
  "params": { "formId": "landing-main", "contact": "***67" },
  "error": { "name": "Error", "message": "Сервер ответил статусом 500", "stack": "Error: ...\n    at ..." }
}
```
